# 성과 데이터 시각화 기능 사용자 사용 패턴

> **최종 업데이트**: 2024년 (AdSense 404 오류 수정, GA4 데이터 수집 개선)

## 📊 개요

성과 데이터 시각화 기능은 발행된 콘텐츠의 성과를 시각적으로 분석하고 비교할 수 있도록 도와주는 기능입니다.

## 🔄 최근 업데이트 내역

### 2024년 업데이트
- **AdSense 404 오류 처리 개선**: 리포트 생성 실패 시 데이터 없음으로 처리 (오류 아님)
- **GA4 데이터 수집 개선**: 필터 전략 다각화 및 페이지 경로 매칭 유연성 향상
- **오류와 데이터 없음 구분**: 실제 API 오류와 데이터 없음을 명확히 구분하여 표시

## 🎯 주요 사용 시나리오

### 시나리오 1: 발행 후 성과 추적 시작하기

**사용자 목표**: 발행한 콘텐츠의 성과를 추적하고 싶다.

**사용 흐름**:
1. **기획 보드 접근**
   - Content Pilot 패널 열기
   - 상단 탭에서 "기획 보드" 클릭

2. **발행 완료 카드 찾기**
   - "✅ 발행 완료" 컬럼에서 발행한 콘텐츠 카드 확인
   - 성과 추적이 연결되지 않은 카드는 "🔗 성과 추적" 버튼 표시

3. **성과 추적 연결**
   - "🔗 성과 추적" 버튼 클릭
   - 발행 URL 입력 모달에서 발행된 콘텐츠 URL 입력
   - 플랫폼 자동 감지 (네이버 블로그, 브런치, 유튜브 등)
   - "연결하기" 버튼 클릭

4. **성과 데이터 수집 대기**
   - 성과 추적이 시작되면 자동으로 GA4와 AdSense 데이터 수집
   - 6시간마다 자동 업데이트
   - 카드에 성과 지표 미리보기 표시 (페이지뷰, 수익, 체류 시간)

**예상 소요 시간**: 1-2분

---

### 시나리오 2: 개별 콘텐츠 성과 상세 분석

**사용자 목표**: 특정 콘텐츠의 상세한 성과 데이터를 확인하고 싶다.

**사용 흐름**:
1. **기획 보드에서 카드 확인**
   - "✅ 발행 완료" 컬럼에서 성과 지표가 있는 카드 확인
   - 카드에 성과 미리보기 표시 (👁️ 페이지뷰, 💰 수익, ⏱️ 체류 시간)
   - 카드 왼쪽에 초록색 테두리 표시 (성과 데이터 있음)

2. **상세 모달 열기**
   - 카드의 "📊 상세" 버튼 클릭
   - 성과 상세 분석 모달 열림

3. **성과 지표 확인**
   - **주요 지표 카드**: 페이지뷰, 세션 수, 평균 체류 시간, 평균 페이지 수, 이탈률, 예상 수익, 페이지 RPM, 클릭률(CTR)
   - **시간대별 페이지뷰 추이**: 24시간 동안의 페이지뷰 분포를 막대 그래프로 확인
   - **주요 성과 지표 비교**: 전체 콘텐츠 대비 상대적 성과를 바 차트로 확인
     - 수익 비교 (초록색 그라데이션)
     - 페이지뷰 비교 (파란색 그라데이션)
     - 체류 시간 비교 (빨간색 그라데이션)
   - **주요 유입 경로**: 상위 5개 유입 소스/미디엄 확인

4. **데이터 분석**
   - 시간대별 트래픽 패턴 파악 (언제 가장 많은 방문자가 오는지)
   - 유입 경로 분석 (어디서 트래픽이 오는지)
   - 전체 콘텐츠 대비 상대적 성과 확인

**예상 소요 시간**: 2-3분

---

### 시나리오 3: 전체 콘텐츠 성과 비교 및 분석

**사용자 목표**: 모든 발행 콘텐츠의 성과를 한눈에 비교하고 싶다.

**사용 흐름**:
1. **성과 대시보드 접근**
   - Content Pilot 패널 열기
   - 상단 탭에서 "성과 대시보드" 클릭

2. **전체 통계 확인**
   - **통계 요약 카드**: 총 수익, 총 페이지뷰, 총 세션, 발행 콘텐츠 수

3. **상위 콘텐츠 비교 차트 확인**
   - **💰 상위 5개 콘텐츠 수익 비교**: 수익이 높은 순으로 5개 콘텐츠를 바 차트로 비교
   - **👁️ 상위 5개 콘텐츠 페이지뷰 비교**: 페이지뷰가 높은 순으로 5개 콘텐츠를 바 차트로 비교

4. **정렬 및 필터링**
   - 정렬 옵션 선택:
     - 수익 높은 순 / 낮은 순
     - 페이지뷰 높은 순 / 낮은 순
     - 최근 업데이트 순
   - "🔄 새로고침" 버튼으로 최신 데이터 업데이트

5. **개별 콘텐츠 카드 확인**
   - 각 콘텐츠의 순위, 제목, 주요 지표 확인
   - 카드 클릭 시 상세 모달 열기

**예상 소요 시간**: 3-5분

## 🔄 일반적인 사용 패턴

### 패턴 1: 정기적인 성과 모니터링

**빈도**: 주 1-2회

**활동**:
1. 기획 보드에서 발행 완료 컬럼 확인
2. 성과 지표가 있는 카드들의 미리보기 확인
3. 특정 콘텐츠의 성과가 눈에 띄면 상세 모달 열어서 분석
4. 시간대별 트래픽 패턴과 유입 경로 확인

**목적**: 콘텐츠 성과 추이 파악 및 개선점 도출

---

### 패턴 2: 발행 직후 성과 확인

**빈도**: 콘텐츠 발행 시마다

**활동**:
1. 콘텐츠 발행 완료 후 기획 보드로 이동
2. 해당 카드에 "🔗 성과 추적" 버튼 클릭
3. 발행 URL 입력 및 연결
4. 첫 성과 데이터 수집 대기 (약 6시간 후)
5. 성과 데이터 확인 후 상세 분석

**목적**: 새로 발행한 콘텐츠의 초기 성과 확인

---

### 패턴 3: 성과 기반 콘텐츠 전략 수립

**빈도**: 월 1회

**활동**:
1. 모든 발행 콘텐츠의 성과 데이터 확인
2. 상위 성과 콘텐츠 패턴 분석:
   - 시간대별 트래픽 패턴
   - 유입 경로 분석
   - 주제/키워드 분석
3. 하위 성과 콘텐츠 개선점 도출
4. 다음 콘텐츠 기획에 인사이트 적용

**목적**: 데이터 기반 콘텐츠 전략 수립

---

## 📈 사용자 행동 분석

### 주요 접근 경로

1. **기획 보드 → 카드 클릭 → 상세 모달** (가장 빈번)
   - 개별 콘텐츠 성과 확인
   - 즉시 피드백 필요 시

2. **기획 보드 → 성과 미리보기 확인** (빈번)
   - 빠른 성과 스캔
   - 전체적인 성과 파악

3. **성과 대시보드 → 전체 비교** (구현 완료)
   - 전체 콘텐츠 성과 비교
   - 전략적 의사결정 시
   - 헤더 탭에서 "성과 대시보드" 클릭으로 접근 가능

### 사용자 관심 지표 순위

1. **수익** (💰) - 가장 높은 관심도
   - 카드에 강조 표시
   - 상세 모달에서 하이라이트

2. **페이지뷰** (👁️) - 두 번째 관심도
   - 트래픽 규모 파악

3. **체류 시간** (⏱️) - 콘텐츠 품질 지표
   - 사용자 참여도 파악

4. **유입 경로** - 마케팅 전략 수립
   - 어디서 트래픽이 오는지 확인

5. **시간대별 트래픽** - 콘텐츠 최적화
   - 언제 발행할지 결정

## 🔧 각 사이트 연동 설정 방법

성과 데이터를 수집하기 위해서는 각 사이트(블로그)와 Google 서비스(GA4, AdSense)를 연동해야 합니다.

### 1. Google 계정 연동

**목적**: GA4와 AdSense 데이터에 접근하기 위한 인증

**설정 방법**:
1. Content Pilot 패널 열기
2. 상단 탭에서 "채널 연동" 클릭
3. "🔗 고급 데이터 연동 (수익 분석용)" 섹션 확인
4. "Google 계정으로 로그인" 버튼 클릭
5. Google 계정 선택 및 권한 승인
6. 연동 완료 후 이메일과 AdSense 계정 ID 확인

**확인 사항**:
- ✅ 연동된 계정: 이메일 주소 표시
- ✅ 연동된 애드센스 계정 ID: `pub-...` 형식의 ID 표시

---

### 2. 블로그별 GA4 속성 설정

**목적**: 각 블로그의 Google Analytics 4 데이터 수집

**설정 방법**:
1. "🚀 내 채널" 섹션에서 블로그 추가
2. 블로그 주소 입력 (예: `https://blog.naver.com/your-blog`)
3. "연동할 GA4 속성 선택" 드롭다운에서 해당 블로그의 GA4 속성 선택
   - Google 계정 연동 시 자동으로 사용 가능한 GA4 속성 목록이 표시됩니다
   - 속성 이름과 ID가 함께 표시됩니다 (예: `내 블로그 (123456789)`)
4. "연동 정보 저장" 버튼 클릭

**주의사항**:
- 각 블로그는 하나의 GA4 속성만 연결할 수 있습니다
- 블로그 URL의 도메인과 GA4 속성의 도메인이 일치해야 정확한 데이터를 수집할 수 있습니다
- **하위 도메인 사용 시**: 입력한 정확한 URL을 그대로 사용하세요 (예: `https://costcatcher.k-posting.info`)
  - 시스템이 자동으로 하위 도메인과 메인 도메인을 모두 시도합니다
  - 여러 하위 도메인을 별도로 운영하는 경우, 각각을 별도의 블로그로 추가하면 됩니다
- GA4 속성이 없으면 Google Analytics에서 먼저 생성해야 합니다

---

### 3. 연동 상태 모니터링

**연동 상태 확인**:
- 각 블로그 입력 필드 아래에 연동 상태가 표시됩니다:
  - ✅ **연동 완료**: 모든 설정이 완료되고 테스트 통과
  - ⚠️ **연동 확인 필요**: 설정은 완료되었으나 테스트 필요
  - ❌ **설정 불완전**: 필수 설정이 누락됨

**연동 테스트**:
1. 블로그 입력 필드 아래의 "🔍 테스트" 버튼 클릭
2. GA4와 AdSense API 연결 테스트 실행
3. 결과 확인:
   - **성공**: "GA4: ✅ AdSense: ✅" 표시
   - **실패**: 오류 메시지 확인 및 설정 재점검

**문제 해결**:
- **Google 계정 미연동**: "Google 계정으로 로그인" 버튼 클릭하여 연동
- **AdSense 계정 없음**: Google 계정에 AdSense 계정이 연결되어 있는지 확인
- **GA4 속성 미선택**: 블로그에 해당하는 GA4 속성을 선택
- **API 오류**: Google 계정 권한 확인 및 재연동 시도

---

### 4. 지원 플랫폼별 연동 가이드

#### 네이버 블로그
1. 네이버 블로그에 GA4 추적 코드 설치
2. Content Pilot에서 블로그 URL 입력 (예: `https://blog.naver.com/your-id`)
3. 해당 블로그의 GA4 속성 선택
4. 연동 테스트 실행

#### 브런치
1. 브런치에 GA4 추적 코드 설치
2. Content Pilot에서 블로그 URL 입력 (예: `https://brunch.co.kr/@your-id`)
3. 해당 블로그의 GA4 속성 선택
4. 연동 테스트 실행

#### 티스토리
1. 티스토리 관리자 → 플러그인 → Google Analytics 설정
2. GA4 측정 ID 입력
3. Content Pilot에서 블로그 URL 입력 (예: `https://your-blog.tistory.com`)

### 5. 연동 상태별 시각적 피드백

**기획 보드 카드에서 확인**:
- **✅ 추적 중**: 성과 데이터가 정상적으로 수집되고 있음
- **🔄 수집 중...**: 현재 데이터 수집 진행 중
- **⏳ 추적 대기**: URL은 연결되었으나 아직 데이터 수집 전
- **❌ 미연결**: 발행 URL이 연결되지 않음
- **🔑 인증 필요**: Google 계정 연동 필요
- **⚙️ 설정 필요**: GA4 속성 ID 또는 AdSense 계정 ID 설정 필요
- **⚠️ API 오류**: API 호출 중 오류 발생

**에러 상태 확인**:
- 카드에 빨간색 테두리 표시

- 데이터 소스 상태 표시: `📡 ✅ GA4 ❌ AdSense` 형식으로 개별 상태 확인

### 6. 자주 묻는 질문 (FAQ)

**Q: 여러 블로그를 연동할 수 있나요?**
A: 네, 여러 블로그를 추가하여 각각 다른 GA4 속성과 연결할 수 있습니다.

**Q: GA4 속성이 목록에 나타나지 않아요.**
A: Google 계정을 다시 연동하거나, GA4 속성에 대한 접근 권한을 확인해주세요.

**Q: 연동 테스트가 실패해요.**
A: 다음을 확인해주세요:
- Google 계정 연동 상태
- GA4 속성 ID가 올바른지
- AdSense 계정이 연결되어 있는지
- API 권한이 올바르게 설정되어 있는지

**Q: 데이터가 수집되지 않아요.**
A: 다음을 확인해주세요:
- 발행 URL이 올바르게 연결되었는지
- GA4에서 해당 URL의 데이터가 실제로 수집되고 있는지
- 최소 6시간 이상 경과했는지 (자동 업데이트 주기)

**Q: 하위 도메인을 사용하는데 데이터가 수집되지 않아요.**
A: 하위 도메인을 사용하는 경우:
- 입력한 정확한 URL을 그대로 사용하세요 (예: `https://costcatcher.k-posting.info`)
- 시스템이 자동으로 하위 도메인과 메인 도메인을 모두 시도합니다
- 여러 하위 도메인을 별도로 운영하는 경우, 각각을 별도의 블로그로 추가하세요
- AdSense의 경우, 하위 도메인별로 별도 채널이 설정되어 있을 수 있습니다

**Q: "모든 필터 전략 실패" 또는 "404 오류"가 표시되는데, 실제로는 데이터가 없는 건가요?**
A: 네, 맞습니다. 시스템은 다음과 같이 구분합니다:
- **실제 API 오류**: 401 (인증 오류), 403 (권한 없음), 계정을 찾을 수 없음 등 → 오류로 표시
- **데이터 없음**: 200 OK 응답이지만 해당 URL에 대한 데이터가 없음, 또는 404이지만 계정은 존재 → 0 값으로 정상 처리 (오류 아님)
- 발행 직후에는 데이터가 아직 수집되지 않았을 수 있으므로, 시간이 지나면 자동으로 데이터가 수집됩니다

**Q: GA4 데이터가 NULL로 표시되는데 왜 그런가요?**
A: GA4 데이터 수집 로직이 개선되었습니다:
- 필터 없이 전체 페이지 데이터를 먼저 확인하여 페이지 존재 여부 확인
- 여러 필터 전략 시도 (정확한 경로, trailing slash 제거/추가 등)
- 데이터가 없으면 0 값 반환 (오류 아님)
- 페이지 경로 매칭이 더 유연해져서 다양한 URL 형식을 지원합니다
