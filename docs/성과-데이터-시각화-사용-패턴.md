# 성과 데이터 시각화 기능 사용자 사용 패턴

## 📊 개요

성과 데이터 시각화 기능은 발행된 콘텐츠의 성과를 시각적으로 분석하고 비교할 수 있도록 도와주는 기능입니다.

## 🎯 주요 사용 시나리오

### 시나리오 1: 발행 후 성과 추적 시작하기

**사용자 목표**: 발행한 콘텐츠의 성과를 추적하고 싶다.

**사용 흐름**:
1. **기획 보드 접근**
   - Content Pilot 패널 열기
   - 상단 탭에서 "기획 보드" 클릭

2. **발행 완료 카드 찾기**
   - "✅ 발행 완료" 컬럼에서 발행한 콘텐츠 카드 확인
   - 성과 추적이 연결되지 않은 카드는 "🔗 성과 추적" 버튼 표시

3. **성과 추적 연결**
   - "🔗 성과 추적" 버튼 클릭
   - 발행 URL 입력 모달에서 발행된 콘텐츠 URL 입력
   - 플랫폼 자동 감지 (네이버 블로그, 브런치, 유튜브 등)
   - "연결하기" 버튼 클릭

4. **성과 데이터 수집 대기**
   - 성과 추적이 시작되면 자동으로 GA4와 AdSense 데이터 수집
   - 6시간마다 자동 업데이트
   - 카드에 성과 지표 미리보기 표시 (페이지뷰, 수익, 체류 시간)

**예상 소요 시간**: 1-2분

---

### 시나리오 2: 개별 콘텐츠 성과 상세 분석

**사용자 목표**: 특정 콘텐츠의 상세한 성과 데이터를 확인하고 싶다.

**사용 흐름**:
1. **기획 보드에서 카드 확인**
   - "✅ 발행 완료" 컬럼에서 성과 지표가 있는 카드 확인
   - 카드에 성과 미리보기 표시 (👁️ 페이지뷰, 💰 수익, ⏱️ 체류 시간)
   - 카드 왼쪽에 초록색 테두리 표시 (성과 데이터 있음)

2. **상세 모달 열기**
   - 카드의 "📊 상세" 버튼 클릭
   - 성과 상세 분석 모달 열림

3. **성과 지표 확인**
   - **주요 지표 카드**: 페이지뷰, 세션 수, 평균 체류 시간, 평균 페이지 수, 이탈률, 예상 수익, 페이지 RPM, 클릭률(CTR)
   - **시간대별 페이지뷰 추이**: 24시간 동안의 페이지뷰 분포를 막대 그래프로 확인
   - **주요 성과 지표 비교**: 전체 콘텐츠 대비 상대적 성과를 바 차트로 확인
     - 수익 비교 (초록색 그라데이션)
     - 페이지뷰 비교 (파란색 그라데이션)
     - 체류 시간 비교 (빨간색 그라데이션)
   - **주요 유입 경로**: 상위 5개 유입 소스/미디엄 확인

4. **데이터 분석**
   - 시간대별 트래픽 패턴 파악 (언제 가장 많은 방문자가 오는지)
   - 유입 경로 분석 (어디서 트래픽이 오는지)
   - 전체 콘텐츠 대비 상대적 성과 확인

**예상 소요 시간**: 2-3분

---

### 시나리오 3: 전체 콘텐츠 성과 비교 및 분석

**사용자 목표**: 모든 발행 콘텐츠의 성과를 한눈에 비교하고 싶다.

**현재 상태**: 성과 대시보드 기능은 구현되어 있으나, 헤더 탭에 직접 접근 경로가 없습니다. (향후 추가 예정)

**예상 사용 흐름** (구현 완료 시):
1. **성과 대시보드 접근**
   - Content Pilot 패널 열기
   - 상단 탭에서 "성과 대시보드" 클릭

2. **전체 통계 확인**
   - **통계 요약 카드**: 총 수익, 총 페이지뷰, 총 세션, 발행 콘텐츠 수

3. **상위 콘텐츠 비교 차트 확인**
   - **💰 상위 5개 콘텐츠 수익 비교**: 수익이 높은 순으로 5개 콘텐츠를 바 차트로 비교
   - **👁️ 상위 5개 콘텐츠 페이지뷰 비교**: 페이지뷰가 높은 순으로 5개 콘텐츠를 바 차트로 비교

4. **정렬 및 필터링**
   - 정렬 옵션 선택:
     - 수익 높은 순 / 낮은 순
     - 페이지뷰 높은 순 / 낮은 순
     - 최근 업데이트 순
   - "🔄 새로고침" 버튼으로 최신 데이터 업데이트

5. **개별 콘텐츠 카드 확인**
   - 각 콘텐츠의 순위, 제목, 주요 지표 확인
   - 카드 클릭 시 상세 모달 열기

**예상 소요 시간**: 3-5분

## 🔄 일반적인 사용 패턴

### 패턴 1: 정기적인 성과 모니터링

**빈도**: 주 1-2회

**활동**:
1. 기획 보드에서 발행 완료 컬럼 확인
2. 성과 지표가 있는 카드들의 미리보기 확인
3. 특정 콘텐츠의 성과가 눈에 띄면 상세 모달 열어서 분석
4. 시간대별 트래픽 패턴과 유입 경로 확인

**목적**: 콘텐츠 성과 추이 파악 및 개선점 도출

---

### 패턴 2: 발행 직후 성과 확인

**빈도**: 콘텐츠 발행 시마다

**활동**:
1. 콘텐츠 발행 완료 후 기획 보드로 이동
2. 해당 카드에 "🔗 성과 추적" 버튼 클릭
3. 발행 URL 입력 및 연결
4. 첫 성과 데이터 수집 대기 (약 6시간 후)
5. 성과 데이터 확인 후 상세 분석

**목적**: 새로 발행한 콘텐츠의 초기 성과 확인

---

### 패턴 3: 성과 기반 콘텐츠 전략 수립

**빈도**: 월 1회

**활동**:
1. 모든 발행 콘텐츠의 성과 데이터 확인
2. 상위 성과 콘텐츠 패턴 분석:
   - 시간대별 트래픽 패턴
   - 유입 경로 분석
   - 주제/키워드 분석
3. 하위 성과 콘텐츠 개선점 도출
4. 다음 콘텐츠 기획에 인사이트 적용

**목적**: 데이터 기반 콘텐츠 전략 수립

---

## 📈 사용자 행동 분석

### 주요 접근 경로

1. **기획 보드 → 카드 클릭 → 상세 모달** (가장 빈번)
   - 개별 콘텐츠 성과 확인
   - 즉시 피드백 필요 시

2. **기획 보드 → 성과 미리보기 확인** (빈번)
   - 빠른 성과 스캔
   - 전체적인 성과 파악

3. **성과 대시보드 → 전체 비교** (향후 구현)
   - 전체 콘텐츠 성과 비교
   - 전략적 의사결정 시

### 사용자 관심 지표 순위

1. **수익** (💰) - 가장 높은 관심도
   - 카드에 강조 표시
   - 상세 모달에서 하이라이트

2. **페이지뷰** (👁️) - 두 번째 관심도
   - 트래픽 규모 파악

3. **체류 시간** (⏱️) - 콘텐츠 품질 지표
   - 사용자 참여도 파악

4. **유입 경로** - 마케팅 전략 수립
   - 어디서 트래픽이 오는지 확인

5. **시간대별 트래픽** - 콘텐츠 최적화
   - 언제 발행할지 결정

## 💡 개선 제안

### 단기 개선

1. **성과 대시보드 탭 추가**
   - 헤더에 "성과 대시보드" 탭 추가
   - 전체 콘텐츠 성과 한눈에 보기

2. **성과 알림 기능**
   - 특정 수익/페이지뷰 달성 시 알림
   - 성과 급상승 시 알림

3. **성과 추이 그래프**
   - 시간에 따른 성과 변화 추이
   - 히스토리 데이터 저장 및 시각화

### 장기 개선

1. **AI 성과 분석**
   - 성과 패턴 자동 분석
   - 개선 제안 자동 생성

2. **성과 예측**
   - 머신러닝 기반 성과 예측
   - 목표 달성 가능성 예측

3. **비교 분석**
   - 경쟁 콘텐츠와 비교
   - 업계 평균 대비 성과

## 📝 사용 팁

1. **정기적으로 확인하기**
   - 성과 데이터는 6시간마다 자동 업데이트
   - 주 1-2회 확인 권장

2. **패턴 파악하기**
   - 시간대별 트래픽 패턴을 파악하여 최적 발행 시간 결정
   - 유입 경로 분석으로 마케팅 전략 수립

3. **비교 분석하기**
   - 상위 성과 콘텐츠와 하위 성과 콘텐츠 비교
   - 성공 요인 도출

4. **데이터 기반 의사결정**
   - 직관보다 데이터를 우선
   - 성과 지표를 기반으로 콘텐츠 전략 수립
