## 📝 테스트 시나리오 상세

### 1. 초안 생성 기능 테스트

#### 1.1 기본 초안 생성
**시나리오**: 일반적인 아이디어 카드로 초안 생성
- [ ] 아이디어 카드 선택
- [ ] "초안 생성" 버튼 클릭
- [ ] 로딩 인디케이터 표시 확인
- [ ] AI API 호출 성공 (콘솔에 "API 호출 성공" 로그)
- [ ] 초안 텍스트 생성 완료 (500자 이상)
- [ ] 에디터에 초안 자동 반영
- [ ] SEO 제목 생성 확인 (H1 태그)
- [ ] 저장 버튼 활성화 확인

**기대 결과**: 오류 없이 초안 생성 및 에디터 반영
**시간 제한**: 30초 이내
**실패 시 로그**: `generateDraftFromIdea` 관련 에러

#### 1.2 긴 콘텐츠 초안 생성
**시나리오**: 상세한 설명과 많은 태그가 있는 카드
- [ ] 긴 설명(1000자 이상)과 다수 태그(10개 이상) 설정
- [ ] 초안 생성 실행
- [ ] 프롬프트 최적화 동작 확인 (콘솔에 "프롬프트가 너무 깁니다" 로그)
- [ ] 압축된 프롬프트로도 정상 생성
- [ ] 생성된 초안 품질 유지 (핵심 내용 포함)

**기대 결과**: 긴 프롬프트도 정상 처리
**시간 제한**: 45초 이내

#### 1.3 페르소나별 초안 생성
**시나리오**: 각 페르소나별로 다른 톤의 초안 생성
- [ ] `viral` 페르소나로 생성 → 감성적이고 클릭 유도성 있는 문체
- [ ] `professional` 페르소나로 생성 → 객관적이고 전문적인 문체
- [ ] `friendly` 페르소나로 생성 → 친근하고 대화체 문체
- [ ] 각 초안의 문체 차이 확인

**기대 결과**: 페르소나별로 명확한 문체 차이

### 2. 썸네일 생성 기능 테스트

#### 2.1 기본 썸네일 생성
**시나리오**: 초안 생성 시 썸네일 자동 생성
- [ ] 썸네일 생성 옵션 활성화
- [ ] 초안 생성 완료 후 썸네일 생성 시작 (콘솔에 "썸네일 생성 시작" 로그)
- [ ] AI 이미지 생성 호출 (Gemini Image API)
- [ ] 3가지 비율(1:1, 4:3, 16:9)로 크롭 및 업로드
- [ ] Firebase Storage에 정상 업로드 (URL 반환)
- [ ] 초안 본문에 썸네일 이미지 삽입 확인

**기대 결과**: 3개 비율의 썸네일 URL 생성 및 본문 삽입
**시간 제한**: 60초 이내

#### 2.2 제휴 상품 썸네일 합성
**시나리오**: 제휴 링크가 있는 경우 상품 이미지 합성
- [ ] 제휴 링크가 포함된 아이디어 카드 준비
- [ ] 썸네일 생성 시 상품 이미지 감지 (콘솔에 "제휴 상품 이미지 발견" 로그)
- [ ] AI 합성 프롬프트 생성 및 실행
- [ ] 합성된 썸네일이 상품 특징 반영하는지 확인

**기대 결과**: 상품 이미지가 썸네일에 자연스럽게 합성

#### 2.3 썸네일 생성 실패 처리
**시나리오**: API 실패 시 적절한 폴백 동작
- [ ] 네트워크 차단 또는 API 키 오류 상황 시뮬레이션
- [ ] 썸네일 생성 실패 시에도 초안 생성은 계속 진행
- [ ] 기본 썸네일 후보 텍스트는 유지
- [ ] 사용자에게 오류 알림 표시

**기대 결과**: 썸네일 실패가 전체 플로우를 중단시키지 않음

### 3. 제휴 마케팅 기능 테스트

#### 3.1 제휴 링크 자동 삽입
**시나리오**: 관련 제휴 링크 자동 삽입
- [ ] 제휴 링크 DB에 테스트 데이터 추가
- [ ] 아이디어와 관련된 키워드 포함한 카드 생성
- [ ] 초안 생성 시 관련 링크 필터링 (콘솔에 "관련 링크 발견" 로그)
- [ ] 본문에 자연스러운 링크 삽입 (최대 3개)
- [ ] 링크 스타일 적용 확인 (녹색 배경)
- [ ] 맨 마지막에 대가성 문구 자동 삽입

**기대 결과**: 관련성 높은 링크만 선택적 삽입

#### 3.2 제휴 링크 수동 처리
**시나리오**: 기존 초안에 제휴 링크 수동 삽입
- [ ] 초안 생성 후 제휴 링크 수동 선택
- [ ] `postProcessAffiliateHtml` 함수 호출
- [ ] 기존 링크에 스타일 적용
- [ ] 새로운 링크 삽입 확인

**기대 결과**: HTML 구조 유지하면서 링크 삽입

### 4. 퍼머링크 및 SEO 기능 테스트

#### 4.1 퍼머링크 자동 생성
**시나리오**: SEO 최적화된 URL 생성
- [ ] 한글 제목으로 초안 생성
- [ ] 퍼머링크 자동 생성 (콘솔에 "퍼머링크 생성 시작" 로그)
- [ ] Gemini API로 영문 변환
- [ ] URL 친화적 형식으로 변환 (소문자, 하이픈)
- [ ] 퍼머링크 필드에 자동 입력

**기대 결과**: 검색엔진 친화적인 URL 생성

#### 4.2 JSON-LD 스키마 생성
**시나리오**: 구조화된 데이터 자동 생성
- [ ] 초안 생성 완료 후 JSON-LD 추출 시도
- [ ] 스키마에 필수 필드 포함 (headline, description, datePublished)
- [ ] 채널 정보 기반 author 설정
- [ ] 썸네일 URL을 image 필드에 포함
- [ ] 유효한 JSON 형식 검증

**기대 결과**: 검색엔진 최적화된 구조화 데이터

## 📞 지원 및 문제 해결

### 문제 발생 시 확인사항
1. **콘솔 로그 확인**: 개발자 도구 → Console 탭
2. **네트워크 로그**: Network 탭에서 API 호출 상태 확인
3. **Storage 확인**: Application → Storage → Local Storage
4. **Firebase 상태**: 실시간 데이터베이스 연결 확인

### 긴급 롤백 절차
1. Git에서 이전 커밋으로 복구
2. 확장 프로그램 리로드 (chrome://extensions/)
3. 브라우저 캐시 클리어
4. 사용자 데이터 백업 확인
