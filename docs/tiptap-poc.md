# TipTap POC

이 문서는 프로젝트 내 TipTap 기반 텍스트 에디터 POC 사용법과 실행 방법을 정리합니다.

## 목적
TipTap 및 TipTap UI를 기반으로 기존 Quill 에디터를 교체하기 위한 초기 POC입니다.

## 사용법
1. 의존성 설치:
```bash
npm install
```
2. 로컬에서 `tiptap-poc.html` 파일을 브라우저로 열어 동작을 확인합니다.
