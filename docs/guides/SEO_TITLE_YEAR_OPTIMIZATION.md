# SEO 제목 년도 사용 최적화 가이드

> **최적화 완료일**: 2025-12-31  
> **버전**: v2.0 (년도 스마트 사용)

## 📋 개요

SEO 제목 생성 시 년도를 무분별하게 사용하는 문제를 해결하여, **꼭 필요한 경우에만 년도를 포함**하도록 개선했습니다.

## ❌ 기존 문제점

### 모든 제목에 년도 자동 추가
```
"블로그 시작하는 방법" → "2025년 블로그 시작하는 방법" ❌
"커피 내리는 방법" → "2025년 커피 내리는 방법" ❌
"아이폰 사용 후기" → "2025년 아이폰 사용 후기" ❌
```

**문제**:
- 시간과 무관한 주제에 불필요한 년도 추가
- 매년 제목을 업데이트해야 하는 부담
- 검색 노출에서 오히려 불리할 수 있음

## ✅ 개선 사항

### 1) 스마트 년도 사용 규칙

(중략)

### 2) 중복 년도 제거 (버그 픽스)
- 제목 생성 과정에서 동일한 년도가 여러 번 삽입되던 문제를 해결했습니다.
- 연속 또는 비연속적으로 반복된 같은 연도(예: "2024년 2024년", "스마트홈 2024 추천 - 2024 리뷰")를 자동으로 정리합니다.
- 구현: `removeDuplicateYears` 헬퍼를 강화하여 다양한 케이스(한글 '년' 포함, 구두점/공백 등)를 정리합니다.

#### 1. 년도를 사용해야 하는 경우

| 조건 | 예시 | 이유 |
|------|------|------|
| 아이디어 제목에 이미 년도 명시 | "2025년 스마트폰 추천" | 사용자 의도 반영 |
| 시간에 민감한 트렌드/최신 정보 | "최신 AI 트렌드", "올해의 가전제품" | 최신성 강조 필요 |
| 연도별 비교/분석 | "2025년 전기차 전망" | 년도가 핵심 정보 |
| 특정 년도 통계/데이터 기반 | "2025년 부동산 시장 분석" | 데이터 시점 명시 |

#### 2. 년도를 사용하지 말아야 하는 경우

| 조건 | 예시 | 이유 |
|------|------|------|
| 시간과 무관한 영구 가이드 | "블로그 시작하는 법", "커피 내리는 방법" | 영구적 정보 |
| 제품 리뷰 (년도 없는 제품명) | "아이폰 사용 후기", "맥북 에어 리뷰" | 제품명에 년도 없음 |
| 개념/이론 설명 | "SEO란 무엇인가", "마케팅 기초" | 시간 불변 지식 |
| 일반적인 How-to 콘텐츠 | "사진 잘 찍는 법", "요리 레시피" | 보편적 방법 |

## 🔄 변경 내역

### 1. 프롬프트 개선

#### 기존 프롬프트
```markdown
- **${currentYear}년**을 기준으로 최신 트렌드와 정보를 반영한 제목을 생성하세요.
- 제목에 연도가 들어갈 경우 반드시 **${currentYear}년**을 사용하세요.
```
**문제**: 년도 사용을 권장하는 뉘앙스

#### 개선된 프롬프트
```markdown
**[년도 사용 규칙 - 매우 중요]**
- **기본 원칙**: 년도는 꼭 필요한 경우에만 사용하세요. 불필요하게 년도를 추가하지 마세요.

- **년도를 사용해야 하는 경우** (다음 중 하나라도 해당):
  1. 아이디어 제목에 이미 년도가 명시된 경우
  2. 시간에 민감한 트렌드/최신 정보 주제
  3. 연도별 비교/분석이 필요한 경우
  4. 통계나 데이터가 특정 년도를 기준으로 하는 경우

- **년도를 사용하지 말아야 하는 경우**:
  1. 시간과 무관한 영구적인 가이드/방법
  2. 제품 리뷰 (제품명에 년도가 없는 경우)
  3. 개념/이론 설명
  4. 아이디어 제목에 년도가 없고, 시간에 민감하지 않은 주제

- **년도를 사용할 때**: 반드시 **${currentYear}년**을 사용하세요.
```

### 2. 현재 시점 정보 섹션 개선

#### 기존
```markdown
- 주의: 글을 작성할 때 반드시 **${currentYear}년**을 기준으로 최신 정보를 반영하고, 
  제목이나 본문에 연도가 들어갈 경우 **${currentYear}년**을 사용하세요.
```

#### 개선
```markdown
- **중요**: 년도는 꼭 필요한 경우에만 사용하세요. 
  * 시간에 민감한 트렌드/최신 정보가 아니라면 년도를 생략하세요.
  * 년도를 사용할 때는 반드시 **${currentYear}년**을 사용하세요.
```

### 3. 작성 규칙 강화

```markdown
2. **제목 최적화**: 
   - **년도 사용 원칙**: 위에서 명시한 년도 사용 규칙을 엄격히 따르세요. 
     꼭 필요한 경우에만 년도를 포함하세요.
```

## 📊 실전 예시

### 시나리오 1: 시간 불변 가이드

**아이디어 제목**: "블로그 시작하는 방법"

**기존 생성**:
```
2025년 블로그 시작하는 완벽 가이드 ❌
```

**개선 후 생성**:
```
블로그 시작하는 완벽 가이드 - 초보자도 쉽게 따라하는 7단계 ✅
```

**이유**: 블로그 시작 방법은 시간과 무관한 영구적 정보이므로 년도 불필요

## 🎯 권장 사항

### 제목 생성 시 체크리스트

```
□ 아이디어 제목에 년도가 있는가?
  └ Yes → 년도 포함
  └ No → 다음 단계

□ 시간에 민감한 트렌드/최신 정보인가?
  └ Yes → 년도 포함
  └ No → 다음 단계

□ 연도별 비교/분석이 필요한가?
  └ Yes → 년도 포함
  └ No → 다음 단계

□ 특정 년도 통계/데이터가 핵심인가?
  └ Yes → 년도 포함
  └ No → 년도 생략 ✅
```

### 판단 기준

**년도 포함 키워드**:
- "최신", "트렌드", "전망", "예측"
- "올해", "신제품", "NEW"
- "시장 규모", "통계", "데이터"

**년도 불필요 키워드**:
- "방법", "가이드", "완벽", "초보자"
- "기초", "개념", "이해하기"
- "후기", "리뷰" (제품명에 년도 없는 경우)

## 🔮 향후 개선 방향

1. **AI 학습**: 사용자 피드백 기반 년도 필요성 자동 판단
2. **키워드 분석**: 제목 키워드 자동 분석으로 년도 필요성 예측
3. **A/B 테스트**: 년도 있음/없음 SEO 성과 비교
4. **자동 업데이트**: 년도가 포함된 제목 자동 년도 업데이트 제안
