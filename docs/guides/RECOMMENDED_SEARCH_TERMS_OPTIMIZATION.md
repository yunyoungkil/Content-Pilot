# 추천 검색어 최적화 가이드

> **최적화 완료일**: 2025-12-31  
> **버전**: v2.0 (자료 수집 최적화)

## 📋 개요

추천 검색어 기능을 **초안 작성에 필요한 자료 수집**에 최적화하여, 더 구체적이고 실용적인 검색어를 생성하도록 개선했습니다.

## 🎯 최적화 목표

### 기존 문제점
- ❌ 단순 해시태그 형태의 일반적인 키워드 (`#스마트홈`, `#AI`)
- ❌ 자료 수집 목적 불명확
- ❌ 검색어 활용 방법 미제시
- ❌ 검색어 유형 다양성 부족

### 개선 사항
- ✅ **구체적이고 실용적인 검색어** (`스마트홈 시장 규모 2024`)
- ✅ **자료 수집 목적 명확화** (통계, 사례, 비교 데이터 등)
- ✅ **5가지 유형 균형 제공** (통계, 가이드, 비교, 사례, 트렌드)
- ✅ **활용 가이드 제공** (각 유형별 활용 방법 명시)

## 🔄 변경 내역

### 1. 프롬프트 개선

#### 기존 프롬프트
```
"${contextText}" 주제의 블로그 포스트에 적합한 추천 검색어(태그 형태) 10개를 
JSON 배열 형식으로만 반환해주세요. 
예: ["#스마트홈", "#AI", "#IoT", "#홈오토메이션"]
```

#### 개선된 프롬프트
```
"${contextText}" 주제로 블로그 초안을 작성하기 위해 필요한 자료를 수집할 때 
사용할 검색어 10개를 추천해주세요.

## 검색어 목적
초안 작성 시 인용할 통계, 사례, 전문가 의견, 최신 트렌드, 비교 데이터 등을 
찾기 위한 실용적인 검색어

## 검색어 생성 원칙
1. **구체성**: 실제 검색 시 양질의 자료를 찾을 수 있는 구체적인 키워드
2. **다양성**: 통계, 사례, 가이드, 비교, 리뷰 등 다양한 자료 유형 커버
3. **실용성**: 검색 엔진에 입력했을 때 유용한 결과가 나올 검색어
4. **관련성**: 주제와 직접 관련된 키워드

## 검색어 유형 (균형있게 포함)
- 통계/데이터: "스마트홈 시장 규모 2024"
- 가이드/방법: "스마트홈 설치 가이드"
- 비교/분석: "구글홈 vs 아마존 에코 비교"
- 사례/후기: "스마트홈 구축 사례"
- 최신 트렌드: "2024 스마트홈 트렌드"

JSON 배열 형식으로만 반환. 해시태그(#) 제외.
```

### 2. 초안 생성 프롬프트 개선

#### 추천 검색어 섹션 강화
```markdown
### 7. 추천 검색어 (자료 수집용 - 초안 작성에 필요한 추가 정보를 찾기 위한 검색어)

[추천 검색어 활용 규칙 - 매우 중요]
- 이 검색어들은 **초안 작성에 필요한 추가 자료를 수집하기 위한 목적**으로 생성
- 각 검색어는 특정 유형의 정보를 찾기 위해 최적화

**활용 방법**:
1. 통계/데이터 검색어 → 신뢰성 있는 수치와 데이터 포함
2. 가이드/방법 검색어 → 실용적인 팁이나 단계별 설명
3. 비교/분석 검색어 → 제품/서비스 비교 분석
4. 사례/후기 검색어 → 실제 사용 경험이나 사례 연구
5. 최신 트렌드 검색어 → 최신 동향이나 전망

**예시**:
- 검색어: "스마트홈 시장 규모 2024" 
  → 본문에 "2024년 글로벌 스마트홈 시장은 X조원 규모..." 같은 통계 포함
```

## 📊 검색어 유형별 예시

### 1. 통계/데이터 검색어
**목적**: 본문에 신뢰성 있는 수치 포함

**예시**:
- `전기차 시장 규모 2024`
- `스마트폰 시장 점유율 통계`
- `배터리 수명 데이터`

**초안 활용**:
```markdown
2024년 글로벌 전기차 시장은 약 500조원 규모로 성장할 것으로 전망되며,
연평균 20% 이상의 성장률을 기록하고 있습니다.
```

### 2. 가이드/방법 검색어
**목적**: 실용적인 팁과 단계별 설명 제공

**예시**:
- `전기차 충전 방법 초보자 가이드`
- `스마트홈 설정 단계`
- `블로그 SEO 최적화 방법`

**초안 활용**:
```markdown
## 전기차 충전 방법 (초보자 가이드)

1. 충전 카드 준비하기
2. 충전소 위치 확인하기
3. 충전 커넥터 연결하기
...
```

### 3. 비교/분석 검색어
**목적**: 제품/서비스 비교 분석 섹션 작성

**예시**:
- `테슬라 모델3 vs 아이오닉6 가격 비교`
- `갤럭시 S24 vs 아이폰15 카메라 성능`
- `노션 vs 에버노트 기능 비교`

**초안 활용**:
```markdown
## 테슬라 모델3 vs 아이오닉6 비교

| 항목 | 테슬라 모델3 | 아이오닉6 |
|------|-------------|-----------|
| 가격 | 5,500만원 | 5,200만원 |
| 주행거리 | 528km | 519km |
...
```

### 4. 사례/후기 검색어
**목적**: 실제 사용 경험 공유

**예시**:
- `스마트홈 구축 사례`
- `전기차 장거리 운행 후기`
- `블로그 수익화 성공 사례`

**초안 활용**:
```markdown
## 실제 사용자 사례

"30평대 아파트에 스마트홈을 구축한 A씨는 월 전기료를 20% 절감했습니다.
특히 외출 모드 설정으로 불필요한 대기전력을 차단한 것이 효과적이었다고..."
```

### 5. 최신 트렌드 검색어
**목적**: 최신 동향 및 전망 제시

**예시**:
- `2024 전기차 신기술 트렌드`
- `AI 스마트홈 최신 동향`
- `블로그 마케팅 트렌드 2024`

**초안 활용**:
```markdown
## 2024년 전기차 트렌드

올해는 특히 '800V 초고속 충전'과 'V2L(차량 전력 공급)' 기능이 주목받고 있습니다.
현대차의 경우 18분 만에 10%에서 80%까지 충전이 가능한 시스템을 선보였으며...
```

## 🔧 사용 방법

### 1. 브리핑 생성 시 자동 생성
```javascript
await generateIdeaBriefing(cardId, title, description, {
  generateKeywords: true, // 추천 검색어 생성 활성화
});
```

### 2. 생성된 검색어 확인
워크스페이스의 "추천 검색어" 탭에서 확인 가능

### 3. 초안 작성 시 자동 활용
AI 초안 생성 시 추천 검색어가 자동으로 프롬프트에 포함되어, 해당 유형의 정보가 본문에 반영됩니다.

- 어떤 유형의 정보를 찾아야 할지 불명확

```json
[
  "스마트홈 시장 규모 2024",
  "스마트홈 설치 가이드 초보자",
  "구글홈 vs 아마존 에코 비교",
  "스마트홈 구축 사례",
  "2024 스마트홈 신제품 트렌드",
  "스마트홈 기기 호환성 문제",
  "스마트싱스 허브 설정 방법",
  "스마트홈 보안 취약점",
  "음성인식 스피커 정확도 테스트",
  "스마트홈 전기료 절감 효과"

```
**장점**:
- ✅ 구체적이고 실용적
- ✅ 검색 시 양질의 자료 확보 가능
- ✅ 5가지 유형 균형있게 포함 (통계 2개, 가이드 2개, 비교 1개, 사례 1개, 트렌드 1개, 문제해결 3개)
- ✅ 초안 작성 시 각 섹션에 활용 가능

## 🎯 권장 사항

### 검색어 생성 시
1. **주제 명확화**: 구체적인 제목과 설명 제공
2. **키워드 옵션 활성화**: `generateKeywords: true` 설정
3. **결과 검증**: 생성된 검색어가 자료 수집에 적합한지 확인

### 초안 작성 시
1. **검색어 유형 이해**: 각 검색어가 어떤 유형의 정보를 암시하는지 파악
2. **균형있는 활용**: 5가지 유형의 정보를 골고루 본문에 포함
3. **구체적인 정보 제공**: 추상적인 설명보다 통계, 사례, 비교 등 구체적 정보 우선

## 🔮 향후 개선 방향

1. **검색어 품질 평가**: 생성된 검색어의 실제 검색 결과 품질 분석
2. **사용자 피드백**: 검색어 유용성에 대한 사용자 피드백 수집
3. **개인화**: 사용자의 작성 스타일에 맞는 검색어 추천
4. **자동 검색**: 추천 검색어로 자동 검색 후 결과 요약 제공
