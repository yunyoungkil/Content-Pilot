# 작업 로그 인덱스 (Work Log Index)

이 문서는 Content Pilot 프로젝트의 모든 작업 내역을 추적하고 관리하기 위한 인덱스입니다.

## 📋 문서 구조

### 1. 프로그램 로직 문서
- **[PROGRAM_LOGIC.md](./PROGRAM_LOGIC.md)**: 전체 프로그램 로직 및 아키텍처 상세 설명
- **[DATA_FLOW.md](./DATA_FLOW.md)**: 데이터 흐름 및 상태 관리 상세 설명
- **[SERVICE_INTERACTIONS.md](./SERVICE_INTERACTIONS.md)**: 서비스 간 상호작용 및 통신 패턴

### 2. 리팩토링 가이드
- **[REFACTORING_GUIDE.md](./REFACTORING_GUIDE.md)**: 리팩토링 가이드 및 베스트 프랙티스
- **[REFACTORING_HISTORY.md](./REFACTORING_HISTORY.md)**: 리팩토링 이력 및 변경 사항

### 3. 버그 해결 로그
- **[BUG_FIX_LOG.md](./BUG_FIX_LOG.md)**: 버그 해결 이력 및 해결 방법
- **[ERROR_PATTERNS.md](./ERROR_PATTERNS.md)**: 자주 발생하는 에러 패턴 및 해결 방법

### 4. 작업 문서화 시스템
- **[WORK_SESSION_LOG.md](./WORK_SESSION_LOG.md)**: 작업 세션 추적 및 기록
- **[WORK_DOCUMENTATION_GUIDE.md](./WORK_DOCUMENTATION_GUIDE.md)**: 작업 문서화 방법 가이드
- **[DETAILED_LOGIC_TEMPLATE.md](./DETAILED_LOGIC_TEMPLATE.md)**: 프로그램 로직 상세 기록 템플릿
- **[TASK_MANAGEMENT.md](./TASK_MANAGEMENT.md)**: 복잡한 작업을 세분화된 테스크로 관리

### 5. 작업 일지
- **[WORKLOG_YYYY-MM-DD.md](./worklog/)**: 날짜별 상세 작업 내역

## 📅 최근 작업 내역

### 2024년 작업
- 작업 문서화 시스템 구축 (2024-12-XX)
  - 작업 세션 로그 시스템 구축
  - 작업 문서화 가이드 작성
  - 프로그램 로직 상세 기록 템플릿 생성
  - 테스크 관리 시스템 구축

## 📝 작업 로그 작성 가이드

새로운 작업을 시작할 때는 다음 가이드를 참고하세요:

### 빠른 시작
1. **작업 시작 전**: [작업 문서화 가이드](./WORK_DOCUMENTATION_GUIDE.md) 참고
2. **작업 세션 기록**: [작업 세션 로그](./WORK_SESSION_LOG.md)에 새 항목 추가
3. **복잡한 작업**: [테스크 관리](./TASK_MANAGEMENT.md)로 테스크 분해
4. **복잡한 로직**: [상세 로직 템플릿](./DETAILED_LOGIC_TEMPLATE.md) 사용

### 상세 가이드
- **작업 문서화 방법**: [작업 문서화 가이드](./WORK_DOCUMENTATION_GUIDE.md) 참고
- **작업 세션 기록**: [작업 세션 로그](./WORK_SESSION_LOG.md) 형식 참고
- **테스크 분해**: [테스크 관리](./TASK_MANAGEMENT.md) 가이드 참고
- **로직 상세 기록**: [상세 로직 템플릿](./DETAILED_LOGIC_TEMPLATE.md) 사용
